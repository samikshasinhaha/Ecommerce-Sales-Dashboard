# Ecommerce-Sales-Dashboard
Interactive Excel dashboard project analyzing e-commerce sales data using Pivot Tables, Charts, Slicers, KPI Cards, and Business Insights.

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to generate business insights and interactive dashboards.

The dashboard helps stakeholders track:
- Sales performance
- Profit trends
- Regional analysis
- Customer behavior
- Product category performance

---

## Tools & Features Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- KPI Cards
- Data Cleaning
- Business Reporting

---

## Dataset Information
The dataset contains:
- Order details
- Sales values
- Profit data
- Customer information
- Product categories
- Regional performance

---

## Business Objectives
- Identify top-performing categories
- Analyze profit and sales trends
- Track regional performance
- Understand customer purchasing behavior
- Build an interactive business dashboard

---

## Dashboard Features
- Dynamic KPI Cards
- Interactive Slicers
- Monthly Sales Trend Analysis
- Top Products Analysis
- Regional Performance Tracking
- Profitability Insights

---

## Key Insights
- Highest sales generated from top-performing regions
- Certain categories contribute higher profits despite lower sales
- Seasonal sales spikes observed in specific months
- Customer segments show different purchasing patterns
